H-E-S-M: Hormonal, Environmental, State, Nutrient Matrix
A comparative research framework by Kyle James Harrison
Camrose, Alberta, Canada

Welcome to the H-E-S-M project.

This whitepaper presents an open-research framework for studying recurring patterns across plant regeneration, crop development, nutrient processing, tissue engineering, and closed ecological systems. It is intended for researchers, students, clinicians, bioengineers, and independent investigators who want a shared language for comparing complex biological systems without confusing analogy with clinical proof.

The central idea is simple:

Activation
→
Stabilization
→
Storage/Integration
→
System maintenance
Activation→Stabilization→Storage/Integration→System maintenance
Loop One applies this sequence across apple wound-induced organogenesis, citrus anther culture, sweet-potato storage-root formation, wheat cultivation in closed life-support systems, and a parallel human nutrient-processing pathway.

This work is meant to be read, questioned, tested, expanded, challenged, and improved. H-E-S-M is not presented as a finished clinical model. It is a structured hypothesis-generation architecture: a way to organize evidence, identify meaningful correspondences, and design better experiments across disciplinary silos.

If you use, adapt, cite, critique, or build on this framework, you are welcome to do so in the spirit of open research. Please preserve clear distinctions between:

Structural analogy — similar organization or sequence.

Functional analogy — similar systems-level role.

Mechanistic overlap — shared or related biological pathway.

Clinical equivalence — direct, evidence-based human health effect.

Only the last category should ever inform medical decisions, and it requires independent clinical validation.
